# Frontend - AASANA

## Vistas incluidas

- Login
- Tablero publico
- Gestion de vuelos
- Registro de vuelo
- Detalle de vuelo
- Dashboard gerencial
- Reportes
- CRUD aerolineas
- CRUD aeropuertos

## Ejecutar

1. Copiar `.env.example` en `.env.local`
2. Ejecutar `npm install`
3. Ejecutar `npm run dev`

## Nota

La variable `NEXT_PUBLIC_API_URL` debe apuntar al backend FastAPI.
